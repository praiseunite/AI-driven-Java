Platform & tooling

Algorithm

A precise, step-by-step recipe for solving a problem, with no ambiguity.

Bytecode (.class)

The intermediate, platform-independent instructions produced by javac. The JVM runs bytecode, not your source.

Compiler

A tool that translates a whole program at once into another form. Java's is javac: .java → .class.

Interpreter

A tool that reads and executes code line by line at runtime rather than translating it all up front.

JDK (Java Development Kit)

The full toolkit for writing Java: JRE + javac, jar, jdb, javadoc. What a developer installs.

JRE (Java Runtime Environment)

JVM + standard libraries. Enough to run Java apps, not to compile them.

JVM (Java Virtual Machine)

The software engine that loads and executes bytecode, translating it to your CPU's machine code as it runs (via the JIT compiler).

JIT (Just-In-Time) compiler

A part of the JVM that converts frequently-run bytecode into fast native machine code while the program runs.

javac

The Java compiler command. javac Hello.java produces Hello.class.

java

The launcher command. java Hello starts the JVM and runs Hello.class from its main method. No file extension.

IDE

Integrated Development Environment — an editor that also compiles, runs, and debugs. This course uses IntelliJ IDEA Community.

PATH

A list of folders your terminal searches for commands. The JDK's bin must be on it for javac/java to work anywhere.

JAVA_HOME

An environment variable pointing at your JDK install folder. Many tools read it to find Java.

WORA ("Write Once, Run Anywhere")

Java's promise: compile to bytecode once, and it runs unchanged on any OS that has a JVM.

JAR

A single zipped archive of .class files (and resources). An executable JAR names a main class and runs with java -jar app.jar. (Session 7.)

Program structure

Class

A named block that holds code. In Java every line of code lives inside a class. Also a blueprint for objects (Week 2).

Method

A named, reusable block of statements, e.g. main. It can take inputs (parameters) and give back a result (return value).

main method

The exact entry point the JVM looks for: public static void main(String[] args). Execution starts here.

Statement

One complete instruction, ended with a semicolon ;.

Block { }

Curly braces grouping statements — the body of a class, method, loop, or if.

Keyword

A word reserved by Java with a fixed meaning (class, public, if, int…). Cannot be used as a name.

Identifier

A name you choose for a class, variable, or method.

Comment

Text the compiler ignores, for humans: // line, /* block */, /** doc */.

Case-sensitive

Java treats Total, total, and TOTAL as three different names.

camelCase / PascalCase

Naming styles: variables & methods use camelCase; classes use PascalCase; constants use UPPER_SNAKE_CASE.

import

A line that makes a class from another package usable by its short name, e.g. import java.util.Scanner;.

Package

A named folder-like grouping of related classes (Session 7).

Variables & data

Variable

A named box in memory that holds a value you can read and change.

Data type

What kind of value a variable holds and how big it is (int, double, boolean, String…).

Primitive type

One of Java's 8 built-in simple types that store a raw value directly: byte, short, int, long, float, double, char, boolean.

Reference type

A variable that holds the address of an object (e.g. String, arrays, any class). The object lives on the heap.

Literal

A fixed value written directly in code: 42, 3.14, 'A', "hi", true.

Literal suffix

A trailing letter setting a number's type: 100L (long), 9.99f (float).

Initialise

Give a variable its first value: int x = 5;.

Constant (final)

A variable whose value cannot change after it is set: final int MAX_TRIES = 3;.

Stack

Fast, orderly memory for method calls and their local primitive variables. Frees automatically when a method returns.

Heap

Flexible memory where objects live. Cleaned up by the garbage collector when nothing refers to them.

Type casting

Converting a value from one type to another.

Widening (implicit)

Small type → larger type. Safe and automatic: int → double.

Narrowing (explicit)

Larger type → smaller type. Requires (type) and may lose data: (int) 8.95 → 8.

Truncation

Dropping the fractional part with no rounding, during integer division or narrowing.

Overflow

A value too big for its type wraps around to a wrong number (e.g. int past ~2.1 billion).

Floating-point imprecision

double/float cannot store every decimal exactly, so 0.1 + 0.2 != 0.3. Use rounding for display, BigDecimal for real money.

String

A sequence of characters. A reference type, and immutable (methods return a new String rather than changing it).

Concatenation

Joining strings (and other values turned into text) with +.

Escape sequence

A backslash code inside a string: \n newline, \t tab, \" quote, \\ backslash.

Operators

Operator

A symbol that computes a value from one or more operands: + - * / %, && || !, == < >…

Arithmetic operators

+ - * / and % (modulus / remainder).

Integer division

Dividing two ints throws away the remainder: 7 / 2 is 3. Use a double operand for 3.5.

Modulus (%)

The remainder after division: 17 % 5 is 2. n % 2 == 0 tests "even".

Relational operators

== != < > <= >= — compare two values, produce a boolean.

Logical operators

&& (and), || (or), ! (not) — combine booleans.

Short-circuit evaluation

&& stops at the first false; || stops at the first true. The rest is not evaluated.

Assignment (=)

Puts the value on the right into the variable on the left. Not the same as ==.

Compound assignment

+= -= *= /= %=. total += x means total = total + x.

Increment / decrement

++ adds 1, -- subtracts 1. i++ (post) uses the old value first; ++i (pre) changes it first.

Ternary operator

condition ? valueIfTrue : valueIfFalse — a compact if/else that produces a value.

Operator precedence

The order operators apply: *///% before +/-; comparisons before &&/||. Parenthesise when unsure.

Math

A built-in class of maths helpers: Math.abs, Math.pow, Math.sqrt, Math.round, Math.random, Math.PI.

Input & output

System.out.println

Prints its argument and moves to a new line.

System.out.print

Prints without moving to a new line — the cursor stays put.

System.out.printf

Prints using a format string: %d int, %f float, %.2f 2 decimals, %s string, %n newline, %-10s left-align in 10.

Standard output (stdout)

The normal text stream a program writes to — your console.

Scanner

A class (from java.util) that reads typed input: nextInt(), nextDouble(), nextLine().

nextLine() gotcha

After nextInt()/nextDouble(), a leftover newline makes the next nextLine() return "". Add an extra nextLine() to consume it.

Command-line argument

A value passed at launch, arriving in String[] args. java Greet Ada → args[0] is "Ada".

Control flow

Control flow

The order statements run in. Default is top to bottom; branches and loops change it.

Branching / selection

Choosing which code to run: if, if-else, else-if ladder, switch.

switch

Matches one value against constant cases. Classic form needs break;; arrow form case x -> ... does not (Week 4).

Fall-through

In a classic switch, forgetting break; so execution runs on into the next case.

default

The catch-all branch of a switch when no case matches.

Loop / iteration

Repeating a block: for, while, do-while.

Entry-controlled loop

Tests the condition before the body (for, while) — may run 0 times.

Exit-controlled loop

Tests after the body (do-while) — always runs at least once.

Iteration (one)

A single pass through a loop body.

Nested loop

A loop inside a loop. Inner runs fully for each outer pass — 4 × 5 = 20 total.

break

Exit the enclosing loop (or switch) immediately.

continue

Skip the rest of this iteration and go to the loop's next step.

Off-by-one error

Looping one time too many or too few — usually < vs <= or starting at 0 vs 1.

Infinite loop

A loop whose condition never becomes false. Stop a runaway one with Ctrl+C (terminal) or the red ■ (IDE).

Loop patterns

Accumulator (total += x), counter/filter (if (c) count++), sentinel/early-exit (if (found) break), digit extraction (d = n % 10; n /= 10).

Trace / dry run

Stepping through code by hand, writing each variable's value after every line, to predict the output.

Errors & debugging

Syntax / compile-time error

Invalid Java; javac refuses to build. Points at a file and line.

Runtime error / exception

A failure while the program runs (bad data, null, divide-by-zero).

Logic error

It compiles and runs but gives the wrong answer. Only tracing/testing finds these.

Exception

An object representing a runtime problem, e.g. NullPointerException, ArithmeticException. (Handled properly in Session 11.)

Stack trace

The list of method calls printed when an exception is not handled. Read top-down; find the first line naming your file.

NullPointerException

Using a reference that is null as though it points to an object.

Debugging

Finding and removing defects — by reading errors, tracing, testing small pieces, and using a debugger.

Breakpoint

A marker where the IDE debugger pauses so you can inspect variables (introduced later).

Objects & OOP (Week 2 onward — preview)

Structured / procedural programming

Organising code as sequences of procedures acting on separate data (C, Pascal).

Object-Oriented Programming (OOP)

Organising code as objects that bundle data (state) with the methods that act on it (behavior).

Object

A specific thing with state and behavior, built from a class.

State / attribute / field

The data an object holds (a car's color, speed).

Behavior

What an object can do — its methods (accelerate()).

Constructor

A special method that runs when an object is created, to set it up.

Encapsulation

Keeping data private and exposing controlled methods, so objects cannot be corrupted from outside.

Inheritance

A class reusing and extending another class's members with extends. (Session 9.)

Polymorphism

One method call behaving differently depending on the actual object type. (Session 9.)

static

Belongs to the class itself, not to any one object — callable without creating an instance. That is why main is static.

void

A method return type meaning "returns no value".

null

A reference that points at no object.

Array

A fixed-size, indexed collection of values of one type. Indexes run 0 to length - 1. (Session 6.)
