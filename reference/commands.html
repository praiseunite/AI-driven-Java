Commands: IDE ↔ Terminal

The IDE's buttons are shortcuts for terminal commands. Knowing both means you are never stuck on a machine without your favourite editor, and you actually understand what "Run" does. Every row below is the same action, two ways.

Core workflow

GoalIn IntelliJ IDEAIn the terminal
Create a project Welcome screen → New Project → Java, pick JDK → Create mkdir MyApp && cd MyApp (just a folder)
Add a class Right-click src → New → Java Class → name it Create a file MyClass.java in your editor
Compile Automatic on save; or Build → Build Project (Ctrl+F9) javac MyClass.java → produces MyClass.class
Run Click the green ▶ next to main → Run (Shift+F10 re-runs) java MyClass  (no .class, no .java)
Compile many files Automatic javac *.java  or  javac -d out src/*.java
See compiled output location out/production/<project>/ inside the project Next to the source, unless you used -d <folder>
Run a single file quickly (JDK 11+) Green ▶ java MyClass.java  (compiles + runs in memory, one file only)

ℹ️ Arguments vs input

Arguments are given once, at launch (args[0], args[1]…). Input is typed while the program runs and is read with Scanner. They are different things.

Feeding input to Scanner without typing it every time

Useful for testing a program that reads several lines. You "pipe" the lines in:

Terminal (macOS / Linux / Git Bash)
printf '2026\n1\n5\n' | java AtmBankingEngine
Terminal (Windows PowerShell)
"2026`n1`n5" | java AtmBankingEngine

Each \n (or `n in PowerShell) is one press of Enter. In IntelliJ you just type into the Run panel, or tick "Redirect input from" in the run configuration and point it at a text file.

Packaging an executable JAR (Session 7)

In IntelliJ IDEAIn the terminal
File → Project Structure → Artifacts → + → JAR → From modules with dependencies → pick the main class → OK. Then Build → Build Artifacts → Build. javac -d out src/*.java
jar --create --file app.jar --main-class MyClass -C out .
java -jar app.jar

The mental model

What "Run" really does
  MyClass.java   --javac-->   MyClass.class   --java-->   output on screen
  (your text)                 (bytecode)                  (program runs)

The IDE watches your files, runs javac for you when they change, then runs java when you click ▶ — plus it manages folders, the classpath, and arguments. Nothing magic; just automation.
