Environment Setup

You need two things to write Java: a JDK (the engine that compiles and runs your code) and a code editor. We install both, then prove they work. Follow the section for your operating system. If you hit an error, jump to Troubleshooting — almost every beginner problem is listed there.

What you are installing (and why)

ToolWhat it doesDo I need it?
JDK (Java Development Kit) Contains javac (compiler), java (launcher), and the standard libraries. Turns your .java text into a running program. Required. Nothing works without it.
IntelliJ IDEA Community A free editor that highlights mistakes as you type, runs your code with one click, and helps you navigate. Recommended. This course teaches with it.
A terminal (PowerShell / Terminal) Already on your computer. We use it to run javac and java by hand so you understand what the IDE does for you. Already installed.
📦 JDK vs JRE vs JVM (30-second version)

JVM runs compiled code. JRE = JVM + libraries (for people who only run Java apps). JDK = JRE + developer tools (for people who write Java — you). Install the JDK and you have all three. Session 1 explains this properly.

We use Eclipse Temurin, a free, production-grade JDK. This course standardises on the current LTS (Long-Term Support) release, JDK 25. Any version 17 or higher will run the code in Weeks 1–4, but install JDK 25 so screenshots and version strings match.

JDK — Windows

  1. Download the installer

    Go to adoptium.net/temurin/releases. Choose: Operating System Windows, Architecture x64, Package Type JDK, Version 25 - LTS. Download the .msi file.

  2. Run the installer

    Double-click the .msi. On the "Custom Setup" screen, click the dropdown next to "Set JAVA_HOME variable" and "Add to PATH" and choose "Will be installed on local hard drive". This one step prevents the most common beginner error.

  3. Finish and reopen your terminal

    Close any PowerShell or Command Prompt windows that were already open — they will not see the new settings until reopened.

Now skip to Verify the JDK.

JDK — macOS

Option A — installer (simplest):

  1. Download

    At adoptium.net/temurin/releases choose OS macOS, Architecture aarch64 for Apple Silicon (M1/M2/M3/M4) or x64 for older Intel Macs, Package JDK, Version 25 - LTS. Download the .pkg.

  2. Run the .pkg and follow the prompts. Temurin's installer sets everything up for you.

Option B — Homebrew (if you already use it):

Terminal
brew install --cask temurin@25

Now go to Verify the JDK.

JDK — Linux

Debian / Ubuntu:

Terminal
sudo apt update
sudo apt install temurin-25-jdk    # if the Adoptium apt repo is configured
# OR the distribution build:
sudo apt install openjdk-25-jdk

Fedora / RHEL:

Terminal
sudo dnf install java-25-openjdk-devel

Prefer the package named ...-jdk or ...-devel (it has javac), not the plain jre package. Then go to Verify the JDK.

Verify the JDK

Open a fresh terminal and run both commands:

Terminal
java -version
javac -version
You should see something like:
openjdk version "25.0.3" 2026-04-21 LTS
OpenJDK Runtime Environment Temurin-25.0.3+9 (build 25.0.3+9-LTS)
OpenJDK 64-Bit Server VM Temurin-25.0.3+9 (build 25.0.3+9-LTS, mixed mode, sharing)

javac 25.0.3

The exact numbers do not matter. What matters is that both commands print a version and neither says "not found" or "not recognized". If one fails, go straight to Troubleshooting before continuing.

Install IntelliJ IDEA Community Edition

  1. Download

    Go to jetbrains.com/idea/download. Scroll to "IntelliJ IDEA Community Edition" — the free one — not the paid Ultimate trial at the top. Download for your OS.

  2. Install

    Windows: run the .exe, accept defaults. macOS: open the .dmg, drag IntelliJ to Applications. Linux: extract the .tar.gz and run bin/idea.sh, or install from the Snap/Toolbox.

  3. First launch

    Accept the privacy notice. You can skip the account sign-in. Choose any UI theme.

First run in IntelliJ — prove everything works

  1. New Project. On the welcome screen click New Project.
  2. Settings: Language Java, Build system IntelliJ, and for JDK pick the "25" you just installed (IntelliJ usually detects it; otherwise choose "Add JDK" and point it at the install folder). Untick "Add sample code". Name it HelloJava. Click Create.
  3. New class: right-click the src folder → New → Java Class → type HelloWorld → Enter.
  4. Type this (do not paste):
    JavaHelloWorld.java
    public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World! My setup works.");
    }
}
  5. Run it: click the green ▶ triangle in the left margin next to main → Run 'HelloWorld.main()'.
The Run panel at the bottom should show:
Hello, World! My setup works.

Process finished with exit code 0
▶ Now do the same thing from the terminal

So you understand what IntelliJ did for you. In your project's src folder:

Terminal
javac HelloWorld.java     # compile -> creates HelloWorld.class
java HelloWorld           # run    -> no .class extension!

Same output. The IDE just runs these two commands (and more) behind a button.

Alternative: Visual Studio Code

If your centre uses VS Code instead, install it from code.visualstudio.com, then install the "Extension Pack for Java" (by Microsoft) from the Extensions panel. You still need the JDK from the sections above. Create a .java file, and VS Code shows a Run link above main. The terminal commands are identical.

Everything in this course works in either editor. Screens and menu names in the lessons refer to IntelliJ.

Troubleshooting

🚨 'javac' is not recognized as an internal or external command (Windows)

The JDK's bin folder is not on your PATH. Fix it:

  1. Press Win, type "environment variables", open "Edit the system environment variables" → Environment Variables…
  2. Under System variables select Path → Edit → New, and add the JDK bin folder, e.g. C:\Program Files\Eclipse Adoptium\jdk-25.0.3.9-hotspot\bin.
  3. Also add a system variable JAVA_HOME = C:\Program Files\Eclipse Adoptium\jdk-25.0.3.9-hotspot (the folder without \bin).
  4. Click OK on every window, then open a brand-new terminal and retry javac -version.
🚨 java: command not found (macOS / Linux)

The shell cannot find Java. Check what is installed:

Terminal
# macOS
/usr/libexec/java_home -V
# Linux
update-alternatives --list java 2>/dev/null || ls /usr/lib/jvm

Then add to ~/.zshrc (macOS) or ~/.bashrc (Linux):

Terminal
# macOS example
export JAVA_HOME=$(/usr/libexec/java_home -v 25)
export PATH="$JAVA_HOME/bin:$PATH"

Run source ~/.zshrc (or open a new terminal) and retry.

⚠️ java -version works but javac -version says "not found"

You installed a JRE, not a JDK. Uninstall it and install a package whose name contains JDK (or -devel on Fedora/RHEL).

⚠️ Wrong version prints (you have several JDKs)

An older Java is earlier on your PATH. On Windows, move the correct bin entry above the others in the Path list (and remove stray entries like C:\ProgramData\Oracle\Java\javapath). On macOS/Linux, make sure your JAVA_HOME/PATH lines point at the version you want and are not overridden later in the file.

⚠️ error: class HelloWorld is public, should be declared in a file named HelloWorld.java

The public class name and the file name must match exactly, including capitals. Rename the file to HelloWorld.java.

⚠️ Error: Could not find or load main class HelloWorld.class

You ran java HelloWorld.class. Drop the extension: java HelloWorld. The java launcher wants a class name, not a file name.

⚠️ IntelliJ: "Project JDK is not defined" / red code everywhere

File → Project Structure → Project, set SDK to your JDK 25 (use "Add SDK → JDK" and browse to the install folder if the list is empty). Then File → Invalidate Caches / Restart if red marks remain.

🚨 Windows SmartScreen / macOS Gatekeeper blocks the installer

Windows: "More info" → "Run anyway" (Temurin and JetBrains installers are signed and safe). macOS: if you see "cannot be opened", go to System Settings → Privacy & Security and click "Open Anyway", or right-click the app → Open.
