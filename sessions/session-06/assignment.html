📋 Assignment 6: Weekly Weather Station Report

Process a week of temperature readings with parallel arrays, the accumulator / min-index / max-index patterns, and a text bar chart built with StringBuilder.

🏢 Scenario

A campus weather station logs one temperature per day for a week. Write WeatherReport.java that summarises the week and prints a simple chart.

Requirements

  1. Data: a String[] days of the 7 day names and a double[] temps of 7 readings (use the values in the expected output).
  2. Average: sum the readings and divide by temps.length (cast to keep decimals). Print with %.2f.
  3. Hottest & coldest day: track the index of the max and min while looping; print the matching day name and temperature.
  4. Days above average: a second pass counting readings greater than the average.
  5. Bar chart: for each day, build a line with the day name, a divider, one # per whole degree ((int) temps[i]), and the numeric value — all assembled in a single StringBuilder, printed once.
Expected Console Output:
=== WEEKLY WEATHER REPORT ===
Average temperature : 22.50 C
Hottest day         : Sat (27.5 C)
Coldest day         : Fri (18.0 C)
Days above average  : 3

Mon | ################### 19.5
Tue | ###################### 22.0
Wed | ######################### 25.5
Thu | ##################### 21.0
Fri | ################## 18.0
Sat | ########################### 27.5
Sun | ######################## 24.0

Readings: {19.5, 22.0, 25.5, 21.0, 18.0, 27.5, 24.0}.
