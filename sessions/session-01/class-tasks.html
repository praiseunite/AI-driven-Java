Programming is a muscle you build by typing code, making mistakes, and debugging them! Complete the three progressive tasks below under your instructor's guidance.

🟢 Level 1: Easy

Task 1.1: The Developer Profile Banner

Objective: Create your very first custom Java file from scratch, compile it using javac, and run it using java to output a stylish developer profile badge to the console.

Instructions:

  1. Create a new file named ProfileBadge.java.
  2. Declare a public class named ProfileBadge.
  3. Write the standard main method entry point.
  4. Use multiple System.out.println() statements to print your full name, student ID, target goal for this course, and a border around it.
Java Starter Skeleton ProfileBadge.java 
public class ProfileBadge {
    public static void main(String[] args) {
        // TODO: Print the top border line
        // TODO: Print your Full Name
        // TODO: Print your Aptech Student ID
        // TODO: Print your career goal (e.g. "Full-Stack AI Developer")
        // TODO: Print the bottom border line

🟡 Level 2: Intermediate

Task 1.2: Exploring println vs. print & Escape Characters

Objective: Discover how System.out.print() differs from System.out.println() and how special escape characters (\n for newline, \t for tab) allow you to format aligned tables.

Instructions:

  1. Create a file named CourseSchedule.java.
  2. Notice that System.out.print() keeps the cursor on the same line, whereas System.out.println() drops to the next line.
  3. Use tab escape characters (\t) and newline characters (\n) to print a clean 3-column table of Week 1 classes.
Java Solution Reference CourseSchedule.java 
public class CourseSchedule {
    public static void main(String[] args) {
        System.out.println("DAY\t\tSESSION\t\tTOPIC");
        System.out.println("----------------------------------------------------------");
        System.out.println("Day 1\t\tSession 1\tIntro to Java & JDK Setup");
        System.out.println("Day 2\t\tSession 2\tVariables, Types & Operators");
        System.out.println("Day 3\t\tSession 3\tDecisions & Loops");
        System.out.println("Day 4\t\tSession 4\tTry It Yourself Review Lab");
    }
}
🔴 Level 3: Challenge

Task 1.3: The Command-Line Argument Greeter

Objective: Demystify what String[] args actually does! Build a program that receives parameters passed when launching the app from the terminal.

Instructions:

  1. Create a file named TerminalGreeter.java.
  2. In your main method, access args[0] (first parameter) and args[1] (second parameter).
  3. Compile with javac TerminalGreeter.java.
  4. Run with two arguments, e.g.: java TerminalGreeter Alice Lagos.
  5. What happens if you run it without arguments? (Observe the ArrayIndexOutOfBoundsException and discuss with instructor!).
Java Code TerminalGreeter.java 
public class TerminalGreeter {
    public static void main(String[] args) {
        // args[0] captures the first word passed in terminal
        // args[1] captures the second word passed in terminal
        System.out.println("Hello, " + args[0] + " from " + args[1] + "!");
        System.out.println("Welcome to Aptech AI-Driven Java Programming.");
    }
}
Terminal Command & Expected Output:
javac TerminalGreeter.java
java TerminalGreeter Ada Abuja

Hello, Ada from Abuja!
Welcome to Aptech AI-Driven Java Programming.
