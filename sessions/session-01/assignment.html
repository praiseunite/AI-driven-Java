📋 Assignment 1: Aptech Smart Campus Registration Receipt

Consolidate your knowledge of class structure, compilation, escape sequences, and console output by solving a real-world campus automation scenario.

🏢 Real-World Business Scenario

The Aptech Student Administration Office is deploying a lightweight console-based terminal kiosk for students who register for the new AI-Driven Java Programming diploma track. Your manager has tasked you with engineering a Java application named CampusReceipt.java that prints a professional, perfectly aligned official registration slip.

Project Specifications & Requirements

  1. Class & File Name: You must create a class named CampusReceipt inside a file named CampusReceipt.java.
  2. Center Header: Display the official header: "APTECH COMPUTER EDUCATION • SMART CAMPUS KIOSK" framed with decorative divider lines.
  3. Registration Information: Use tabs (\t) to align the following fields:
    • Student Full Name
    • Registration Number (e.g. APT/2026/04-098)
    • Module Name: AI-Driven Java Programming (JAVA-I)
    • Batch Code: BTH-2026-MORN
    • Center Location: Victoria Island Center / Abuja Center
    • Date Issued: Current month and year
  4. Financial Breakdown:
    • Tuition Fee • Lab Access Fee • AI Cloud Computing Token Fee
    • Total Amount Paid • Balance Due ($0.00)
  5. Security Footer: Print a validation stamp containing "*** COMPUTER GENERATED OFFICIAL RECEIPT - NO SIGNATURE REQUIRED ***".
  6. Comments: Include clear single-line (//) and multi-line (/* */) comments describing the program purpose and your author details.

Evaluation & Grading Rubric (100 Points Total)

Criteria Description Points
Compilation & Execution Code compiles cleanly with javac CampusReceipt.java with zero errors and executes via java CampusReceipt. 35 Pts
Layout Alignment & Formatting Tabs, borders, and newlines correctly format headers and columns without jagged text edges. 25 Pts
Completeness of Content All required fields (Student ID, Course Track, itemized fees, totals, security stamp) are included. 25 Pts
Code Quality & Comments Proper indentation, clean class structure, and informative author docstrings. 15 Pts
