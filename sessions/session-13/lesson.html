Session 13: The Modern Date and Time API

Dates and times are deceptively hard — months of different lengths, leap years, time zones, daylight saving. Java's modern java.time package (since Java 8) handles all of it with small, immutable, clearly-named types. This session is your working knowledge of it.

🧠 Memory Booster: Flashback
  • Immutability (S6): like String, every java.time type is immutable — methods return a new object.
  • Enums (mentioned S3): DayOfWeek and Month are enums — fixed sets of named constants you can compare and switch on.
  • Static factory methods (S7): you build these with LocalDate.of(...) / .now(), never new.

1. The Core Types

TypeRepresentsExample value
LocalDatea date, no time, no zone2026-04-21
LocalTimea time of day, no date14:30
LocalDateTimedate + time, no zone2026-04-21T14:30
ZonedDateTimedate + time + zone2026-04-21T09:00+01:00[Africa/Lagos]
Periodan amount in years/months/daysP3M6D (3 months, 6 days)
Durationan amount in hours/minutes/secondsPT8H30M
Instanta machine timestamp (UTC)2026-04-21T08:00:00Z

Rule of thumb: "Local" means "wall-clock, no zone attached". Use ZonedDateTime only when zones genuinely matter.

2. Creating Dates & Times

Java
import java.time.*;

LocalDate today   = LocalDate.now();               // the real current date
LocalDate d       = LocalDate.of(2026, 4, 21);     // year, month, day
LocalTime t       = LocalTime.of(14, 30);          // 14:30
LocalTime precise = LocalTime.of(14, 30, 15);      // with seconds
LocalDateTime dt  = LocalDateTime.of(d, t);        // combine
LocalDateTime dt2 = LocalDateTime.of(2026, 4, 21, 14, 30);

LocalDate fromText = LocalDate.parse("2026-12-25");  // ISO format
ℹ️ Month is 1-based here

Unlike the ancient java.util.Calendar (where January was 0), LocalDate.of(2026, 4, 21) means April 21. You can also pass the enum: LocalDate.of(2026, Month.APRIL, 21).

3. They're Immutable — "with" not "set"

There is no setDayOfMonth. Every adjustment returns a new object; the original never changes.

Java
LocalDate d = LocalDate.of(2026, 4, 21);

LocalDate later = d.plusDays(10);        // 2026-05-01
LocalDate back  = d.minusMonths(2);      // 2026-02-21
LocalDate fixed = d.withYear(2030);      // 2030-04-21

System.out.println(d);      // still 2026-04-21 — d was never modified
⚠️ You must capture the result

d.plusDays(10); on its own does nothing. Write d = d.plusDays(10); or store it in a new variable — exactly like String methods.

4. Querying & Enums

Java
LocalDate d = LocalDate.of(2026, 4, 21);

d.getYear();          // 2026
d.getDayOfMonth();    // 21
DayOfWeek dow = d.getDayOfWeek();   // TUESDAY  (an enum)
Month m = d.getMonth();             // APRIL    (an enum)
d.getDayOfYear();     // 111
d.isLeapYear();       // false
d.lengthOfMonth();    // 30

// enums work with switch:
String kind = switch (dow) {
    case SATURDAY, SUNDAY -> "weekend";
    default -> "weekday";
};

5. Comparing

Java
LocalDate a = LocalDate.of(2026, 4, 21);
LocalDate b = LocalDate.of(2026, 5, 1);

a.isBefore(b);     // true
a.isAfter(b);      // false
a.isEqual(b);      // false
a.equals(b);       // false  (also fine for LocalDate)
a.compareTo(b);    // negative

6. Period (dates) vs Duration (times)

JavaDurationPeriod.java
import java.time.*;

// Period: calendar amounts between two DATES
Period p = Period.between(LocalDate.of(2026, 1, 15), LocalDate.of(2026, 4, 21));
p.getMonths();   // 3
p.getDays();     // 6      -> "3 months and 6 days"

// Duration: clock amounts between two TIMES / instants
Duration shift = Duration.between(LocalTime.of(9, 5), LocalTime.of(17, 35));
shift.toHours();        // 8
shift.toMinutesPart();  // 30     -> "8h 30m"
💡 Which one?

Period for human calendar spans ("2 months from now"). Duration for machine time spans ("90 minutes", "elapsed time").

7. ChronoUnit — total counts

When you want a single total ("how many days between?"), use ChronoUnit:

Java
import java.time.temporal.ChronoUnit;

long days   = ChronoUnit.DAYS.between(LocalDate.of(2026, 1, 15), LocalDate.of(2026, 4, 21)); // 96
long months = ChronoUnit.MONTHS.between(LocalDate.of(2026, 1, 1), LocalDate.of(2026, 4, 1)); // 3
long mins   = ChronoUnit.MINUTES.between(LocalTime.of(9, 0), LocalTime.of(10, 30));          // 90

8. Formatting & Parsing with DateTimeFormatter

JavaFormattingDemo.java
import java.time.*;
import java.time.format.DateTimeFormatter;

LocalDateTime dt = LocalDateTime.of(2026, 4, 21, 14, 30);

DateTimeFormatter pretty = DateTimeFormatter.ofPattern("EEE, d MMM yyyy 'at' HH:mm");
String text = dt.format(pretty);          // "Tue, 21 Apr 2026 at 14:30"

// Parse text back — the formatter must match the text
LocalDate d = LocalDate.parse("2026-12-25");                 // ISO, no formatter needed
LocalDate uk = LocalDate.parse("25/12/2026",
        DateTimeFormatter.ofPattern("dd/MM/yyyy"));

9. Time Zones

JavaZonesDemo.java
import java.time.*;

ZoneId lagos = ZoneId.of("Africa/Lagos");
ZoneId tokyo = ZoneId.of("Asia/Tokyo");

ZonedDateTime lagosTime = ZonedDateTime.of(2026, 4, 21, 9, 0, 0, 0, lagos);
ZonedDateTime tokyoTime = lagosTime.withZoneSameInstant(tokyo);

// Lagos : 2026-04-21T09:00+01:00[Africa/Lagos]
// Tokyo : 2026-04-21T17:00+09:00[Asia/Tokyo]
// Same moment in time, different wall-clock readings (Tokyo is 8h ahead).
ℹ️ withZoneSameInstant vs withZoneSameLocal

...SameInstant keeps the moment and changes the clock reading (what you almost always want). ...SameLocal keeps the clock reading and changes the moment.

10. Common Pitfalls

🚨 Ignoring the return value

date.plusDays(7); does nothing. Assign it: date = date.plusDays(7);

🚨 Using new

new LocalDate(...) won't compile. Use the static factories: LocalDate.of(...), .now(), .parse(...).

🚨 Period between two LocalTimes

Period is for dates; Duration is for times. Mixing them gives an UnsupportedTemporalTypeException.

🚨 Formatter pattern doesn't match the text

Parsing "25/12/2026" with pattern "yyyy-MM-dd" throws DateTimeParseException. The pattern must mirror the string exactly.

🚨 Reaching for the old Date / Calendar

They're mutable, zero-based months, and error-prone. Use java.time. Only touch java.util.Date when an old API forces you to.

11. Executive Quick-Recap & Cheat Sheet

⚡ The 30-Second Mental Model

LocalDate / LocalTime / LocalDateTime for zone-free values; ZonedDateTime when zones matter. All immutable — plusX/minusX/withX return new objects you must capture. Build with static .of() / .now() / .parse(). Period = date amount, Duration = time amount, ChronoUnit.X.between = a single total. Format/parse with DateTimeFormatter.ofPattern.

Core Syntax at a Glance

Java Cheat Sheet
import java.time.*;
import java.time.format.DateTimeFormatter;
import java.time.temporal.ChronoUnit;

LocalDate  d  = LocalDate.of(2026, 4, 21);
LocalDate  due = d.plusWeeks(3);
boolean overdue = LocalDate.now().isAfter(due);

long daysLeft = ChronoUnit.DAYS.between(LocalDate.now(), due);

Duration meeting = Duration.between(LocalTime.of(10, 0), LocalTime.of(11, 30));
System.out.println(meeting.toMinutes());        // 90

String label = d.format(DateTimeFormatter.ofPattern("EEEE, d MMMM yyyy"));

ZonedDateTime utc = ZonedDateTime.of(d.atTime(9, 0), ZoneId.of("UTC"));
ZonedDateTime local = utc.withZoneSameInstant(ZoneId.of("Africa/Lagos"));

Plain-English Glossary

LocalDate

A date with no time and no zone.

LocalTime

A time of day with no date.

LocalDateTime

Date + time, still no zone.

ZonedDateTime

Date + time + a specific time zone.

Period

A calendar amount: years, months, days.

Duration

A time amount: hours, minutes, seconds, nanos.

ChronoUnit

An enum of units; UNIT.between(a, b) gives one total.

DateTimeFormatter

Turns date-time objects to/from text using a pattern.

DayOfWeek / Month

Enums of named constants, usable in switch.

ZoneId

A region id like Africa/Lagos that knows offsets and DST.

❓ Q1: Which type should you use for "an employee's shift length"?
Answer: Duration — it's a time amount (hours/minutes). Period is for calendar spans between dates.
❓ Q2: LocalDate d = ...; d.plusMonths(1); System.out.println(d); — what prints?
Answer: The original date. java.time types are immutable; you must write d = d.plusMonths(1);.
❓ Q3: LocalDate.of(2026, 4, 21).getDayOfWeek() returns what kind of thing?
Answer: A DayOfWeek enum constant (here TUESDAY), which you can compare or switch on.
❓ Q4: You have 9:00 UTC and want the Lagos wall-clock time for the same instant. Which method?
Answer: zonedDateTime.withZoneSameInstant(ZoneId.of("Africa/Lagos")) — keeps the moment, changes the displayed time.
