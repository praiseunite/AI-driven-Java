1. Lambdas & Functional Interfaces

A lambda is an unnamed function you can store in a variable or pass to a method. Its type is a functional interface — an interface with exactly one abstract method.

Java
interface Transformer { int apply(int n); }

Transformer doubler = n -> n * 2;          // lambda: parameter -> body
Transformer square  = n -> { return n * n; };  // braces + return for multi-statement

System.out.println(doubler.apply(5));      // 10
System.out.println(square.apply(5));       // 25

Forms: () -> expr (no params), x -> expr (one), (a, b) -> expr (many), x -> { statements; return v; }.

2. Built-in Functional Interfaces (java.util.function)

4. The Streams API

A stream is a pipeline over a data source. You describe what transformations to apply; Java runs them. A pipeline is: source → zero or more intermediate ops (filter, map, sorted) → one terminal op (collect, count, forEach, reduce) that produces a result.

Javaloop vs stream — same result
// Imperative
List<String> result = new ArrayList<>();
for (String s : names) {
    if (s.length() > 3) result.add(s.toUpperCase());
}

// Stream
List<String> result = names.stream()
    .filter(s -> s.length() > 3)
    .map(String::toUpperCase)
    .collect(Collectors.toList());
ℹ️ Lazy & one-shot

Nothing runs until the terminal op. A stream can be consumed once — build a fresh one from the source each time.

7. Generics

You have used generics all course (ArrayList<String>). Writing your own lets a class or method work with any type safely — the compiler checks it, so no casts and no ClassCastException.

JavaGenericsDemo.java
class Box<T> {                       // T is a type parameter
    private T value;
    void put(T value) { this.value = value; }
    T get() { return value; }
}

Box<String> sb = new Box<>();
sb.put("packed");
String s = sb.get();                 // no cast needed

// generic method with a bound: T must be Comparable
static <T extends Comparable<T>> T maxOf(T a, T b) {
    return (a.compareTo(b) >= 0) ? a : b;
}
maxOf(3, 9);                 // 9
maxOf("apple", "pear");      // "pear"

8. var — inferred local types

Java
var count = 0;                              // int
var names = new ArrayList<String>();        // ArrayList<String>
var total = products.stream()...;           // the compiler infers it

for (var p : products) { ... }             // handy in for-each
⚠️ var rules

Local variables only (not fields, not parameters, not return types). It must have an initialiser (var x; is illegal). The type is still fixed at compile time — var is not "dynamic". Use it when the type is obvious from the right-hand side.

9. Switch Expressions

The arrow form from Session 3, now yielding a value — no fall-through, no break.

Java
String size = switch (code) {
    case 1, 2, 3 -> "low";
    case 4, 5, 6 -> "mid";
    default      -> "high";
};

// multi-line branch uses a block + yield
int points = switch (grade) {
    case "A" -> { System.out.println("top marks"); yield 4; }
    case "B" -> 3;
    default  -> 0;
};

10. Records

A record is a compact, immutable data carrier. One line generates the private final fields, the canonical constructor, accessors (x(), y()), and correct equals/hashCode/toString.

Java
record Point(int x, int y) {
    double distanceFromOrigin() { return Math.sqrt(x * x + y * y); }   // you can add methods
}

var p = new Point(3, 4);
p.x();                     // 3   (accessor, no "get")
p.toString();              // "Point[x=3, y=4]"
new Point(3, 4).equals(new Point(3, 4));   // true — value equality for free

Use records for DTOs, coordinates, results, map keys — anywhere you'd otherwise hand-write a small immutable class. (This is the boilerplate you wrote by hand in Session 9's Point.)

11. Text Blocks & Optional

Java
// Text block: multi-line string literal, no \n soup
String json = """
    {
      "name": "Ada",
      "role": "engineer"
    }
    """;

// Optional: a box that is empty or holds one value — models "maybe no result"
Optional<String> found = lookup(key);
String name = found.orElse("unknown");
found.ifPresent(v -> System.out.println("got " + v));
if (found.isPresent()) { ... }
💡 Optional beats returning null

A method returning Optional<T> forces the caller to think about the "nothing found" case — no silent NullPointerException later. Stream ops like findFirst() and max() return Optional.

12. Common Pitfalls

🚨 Reusing a consumed stream

var s = list.stream(); s.count(); s.forEach(...); → "stream has already been operated upon or closed". Start a new stream each time.

🚨 Expecting a stream to mutate the source

Streams don't change the original list. Capture the terminal result.

🚨 var where the type isn't obvious

var x = getData(); hides what x is. Use an explicit type when it aids readability.

🚨 Optional.get() without checking

Throws NoSuchElementException if empty. Use orElse(...) / ifPresent(...) / isPresent().

🚨 Trying to give a record mutable fields

Record components are final. If you need to change state, use a normal class.

13. Executive Quick-Recap & Cheat Sheet

⚡ The 30-Second Mental Model

A lambda (x -> ...) implements a one-method interface; a method reference (Class::m) is a shorter lambda. A stream pipeline = source → filter/map/sorted → a terminal (collect/count/reduce). Generics make your own containers type-safe. var infers a local type; switch expressions yield a value; records are one-line immutable data classes; Optional models "maybe no value".

Core Syntax at a Glance

Java Cheat Sheet
import java.util.*;
import java.util.stream.*;

record Sale(String region, double amount) {}

List<Sale> sales = List.of(
    new Sale("N", 120), new Sale("S", 80), new Sale("N", 60), new Sale("E", 200));

double northTotal = sales.stream()
    .filter(s -> s.region().equals("N"))
    .mapToDouble(Sale::amount).sum();               // 180.0

Map<String, Double> byRegion = sales.stream()
    .collect(Collectors.groupingBy(Sale::region,
             Collectors.summingDouble(Sale::amount)));

Optional<Sale> biggest = sales.stream()
    .max(Comparator.comparingDouble(Sale::amount));

String label = switch (biggest.map(Sale::region).orElse("?")) {
    case "N", "S" -> "domestic";
    default       -> "other";
};

Plain-English Glossary

Lambda

An unnamed function: params -> body.

Functional interface

An interface with exactly one abstract method — a lambda's type.

Method reference

Class::method — a lambda that only calls one method.

Stream

A one-shot pipeline over data; describe transformations, get a result.

Intermediate / terminal op

Lazy transformers (filter, map) vs the final result op.

Collector

Recipe for gathering a stream: toList, joining, groupingBy.

Generic type parameter

<T> — a placeholder the caller fills, checked by the compiler.

var

Compiler-inferred type for a local variable with an initialiser.

switch expression

Arrow-form switch that produces a value; no fall-through.

record

A concise immutable class: fields, constructor, accessors, equals/hashCode/toString auto-generated.

Optional<T>

A container that is empty or holds one value; models "maybe".

Text block

A """-delimited multi-line string literal.

❓ Q1: What makes an interface eligible to be a lambda's target type?
Answer: It must be a functional interface — exactly one abstract method (Runnable, Comparator, Predicate, your own).
❓ Q2: In list.stream().filter(...).map(...).collect(...), which call actually runs the work?
Answer: collect(...) — the terminal operation. Intermediate ops are lazy and do nothing until a terminal op is added.
❓ Q3: What does a record Point(int x, int y) give you for free?
Answer: Private final fields, a canonical constructor, accessors x()/y(), and value-based equals, hashCode, toString.
❓ Q4: Why return Optional<User> instead of User (possibly null)?
Answer: It makes "no result" explicit in the type, forcing the caller to handle it — no silent NullPointerException downstream.
