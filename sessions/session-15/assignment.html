📋 Assignment 15: Expression Evaluator + AI Workflow Log

Two parts. Part A — build a small expression tree evaluated with sealed types and record patterns. Part B — document how you used an AI assistant on Part A: your prompt, its answer, and your review.

Part A — Expression Evaluator (60 pts)

Model an arithmetic expression as a tree and evaluate it recursively. Every node type is a record; the tree type is sealed, so your switch needs no default.

  1. Types (file ExpressionEvaluator.java):
    • sealed interface Expr permits Num, Add, Sub, Mul, Neg {}
    • record Num(double value) implements Expr {}
    • record Add(Expr left, Expr right) implements Expr {} — same shape for Sub, Mul
    • record Neg(Expr operand) implements Expr {}
  2. static double eval(Expr e) — a switch with a record pattern per case; recurse into children; no default.
  3. static String render(Expr e) — pretty-print with parentheses, e.g. ((3 + 4) * -(2 - 5)). Print whole numbers without a trailing .0.
  4. main — build and print (3 + 4) * -(2 - 5) and 10 + (2 * 6).
Expected Console Output:
((3 + 4) * -(2 - 5)) = 21.0
(10 + (2 * 6)) = 22.0

Part B — AI Workflow Log (40 pts)

Somewhere while doing Part A, use an AI assistant (chat or in-editor) for one concrete sub-problem — e.g. "how do record patterns deconstruct a nested record?" or "why won't my sealed switch compile?". Then submit a short markdown file ai-log.md with these sections:

  1. The prompt you sent — verbatim. It should show role/level, the concrete task, constraints (Java 25, concepts through Session 14), and the output shape you asked for.
  2. The AI's answer — pasted (trim to the relevant part).
  3. Your review — for each: did it compile? did you understand every line? Was any API hallucinated or above your level? What did you change, and why? Which edge cases did you test?
  4. Reflection — 3–4 sentences: what the AI sped up, and what you'd have missed if you'd pasted it without review.
⚠️ Academic honesty

The submitted ExpressionEvaluator.java must be code you wrote and can explain line-by-line. Part B rewards honest, critical use of AI — not the absence of it, and not blind copying.
