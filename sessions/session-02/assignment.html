📋 Assignment 2: Retail Point-of-Sale (POS) Billing Engine

Build a financial point-of-sale receipt generator combining primitive variables, compound arithmetic, discount evaluation via ternary operators, and decimal precision formatting.

🏢 Real-World Retail Scenario

The Aptech Campus Tech Store sells developer hardware and accessories. Your supervisor needs a backend invoicing script named RetailBillingEngine.java that automates receipt generation for a customer purchasing three different electronic products.

Project Specifications & Requirements

  1. Class & File Name: RetailBillingEngine.java containing public class RetailBillingEngine.
  2. Variable Definitions: Define variables for three items:
    • Item 1: Mechanical Keyboard ($85.50 each, quantity 2)
    • Item 2: USB-C Multiport Hub ($34.99 each, quantity 1)
    • Item 3: 128GB Fast Flash Drive ($18.75 each, quantity 3)
  3. Financial Computations:
    • Item Subtotals (Unit Price × Quantity).
    • Gross Subtotal (Sum of all 3 items).
    • Promotional Discount: If Gross Subtotal exceeds $150.00, apply an 8% discount (0.08); otherwise apply 0% discount. Use the ternary operator or boolean logic to calculate this!
    • Sales Tax (VAT): 7.5% applied to the discounted subtotal.
    • Final Total Payable: Discounted subtotal + Sales Tax.
    • Cents Truncation: Demonstrate explicit type casting by converting total dollars into total whole cents ((int)(total * 100)).
  4. Formatted Tabular Output: Use System.out.printf() to align names, quantities, and dollar amounts into clean vertical columns.
Target Visual Output (Console Rendering):

Thank you for shopping at Aptech Tech Store!
ℹ️ About this output

The layout above is one acceptable design — your columns and borders may differ. What is graded is that the numbers are correct: gross 262.24, discount 20.98, taxable 241.26, VAT 18.09, final 259.36 (that's %.2f rounding 259.35536), and the explicit cast gives 25935 cents — note (int) truncates 25935.536, it does not round to 25936. A complete, compiled reference implementation is in the solution.
