🧠 Memory Booster: Flashback to Session 1

Before we dive into manipulating numbers and text, let's connect today's lesson with what you learned in Session 1:

  • Where Does Code Live? All code we write today will sit inside a public class, specifically between the curly braces of public static void main(String[] args) { ... }.
  • Compilation vs Execution: If you spell a variable type wrong (e.g. typing Int instead of int), javac will catch it during compilation before the program ever runs!

1. What is a Variable?

When a program runs, it needs to store information temporarily in your computer's RAM (Random Access Memory). A variable is simply a reserved slot in memory that has been given a human-friendly name.

📦 Analogy: The Labeled Cardboard Box

Imagine a warehouse filled with empty cardboard boxes:
1. You slap a sticker label on a box that reads: studentAge.
2. You declare what kind of items can go inside (e.g. only whole numbers).
3. You put the number 21 inside the box.
4. Later on, when the student celebrates a birthday, you can replace the number with 22.

Syntax of Variable Declaration & Initialization:

Java Variable Syntax 
// Step 1: Declaration (Reserve memory of a specific type with a name)
int score;

// Step 2: Initialization (Place the first value inside the box)
score = 95;

// Combined (Declaration + Initialization in one clean step - Best Practice!)
int age = 24;
double hourlyRate = 35.50;
String studentName = "Ada Lovelace";

2. Variable Naming Rules & Best Practices

Java has strict grammatical rules (which cause compiler errors if broken) and community conventions (which make your code readable and professional).

Rule Category Legal Examples ✅ Illegal / Non-Compliant Examples ❌
Cannot start with a digit player1Score, total2 1stPlayer (Compiler Error!)
Allowed characters Letters, numbers, _ (underscore), $ (dollar) user-name, total#, price@tax (Symbols not allowed)
Cannot use Java Keywords classNumber, intVal class, public, static, void (Reserved words!)
Convention: camelCase userAccountBalance, maximumSpeed user_account_balance (Python style), MaxSpeed (Reserved for Classes)

3. The 8 Java Primitive Data Types

Java is a strongly-typed language. That means you must tell the compiler exactly what type of data each variable holds before using it. Java provides 8 foundational building blocks called primitive types:

Type Category Size in RAM Range of Values Example
byte Integer 1 byte (8 bits) -128 to 127 byte age = 25;
short Integer 2 bytes (16 bits) -32,768 to 32,767 short altitude = 15000;
int Integer 4 bytes (32 bits) -2.14 Billion to +2.14 Billion int cityPopulation = 1450000; (Standard integer)
long Integer 8 bytes (64 bits) -9 Quintillion to +9 Quintillion long worldPopulation = 8000000000L; (Notice 'L' suffix)
float Decimal 4 bytes (32 bits) 6 to 7 decimal digits of precision float price = 19.99f; (Notice 'f' suffix)
double Decimal 8 bytes (64 bits) 15 to 16 decimal digits precision double pi = 3.14159265359; (Standard decimal)
char Character 2 bytes (16 bits) Single Unicode character char grade = 'A'; (Enclosed in single quotes)
boolean Truth Value 1 bit (effective) true or false only boolean isEnrolled = true;
💡 The 90% Rule for Everyday Coding

Although there are 8 primitive types, 90% of real-world enterprise code uses just four:
• Whole numbers → use int
• Decimal numbers → use double
• Yes/No flags → use boolean
• Text words and sentences → use String

4. Primitive vs. Reference Types (Strings)

Notice that String is NOT in the list of 8 primitives! A primitive variable holds its raw binary value directly in memory (like a pocket holding a coin). A reference type holds an address (a reference pointer) pointing to a complex object in heap memory.

Java Working with Strings 
// Notice String starts with a capital 'S' because it is a Class!
String firstName = "Ada";
String lastName = "Lovelace";

// String concatenation using the '+' operator
String fullName = firstName + " " + lastName;
System.out.println("Welcome, " + fullName); // Prints: Welcome, Ada Lovelace

// Finding the length of a string
int nameLength = fullName.length();
System.out.println("Character count: " + nameLength); // Prints: 12

5. Escape Sequences

What if you want to print a quotation mark inside a string: She said "Hello"? If you type "She said "Hello"", Java thinks the string ends after said! An escape sequence begins with a backslash (\) and tells the compiler to treat the following character specially:

Escape Code Meaning Code Example Visual Output
\n Newline (moves to the next line) System.out.print("Line 1\nLine 2"); Line 1
Line 2
\t Tab (inserts horizontal spacing) System.out.print("Item:\t$50"); Item:    $50
\" Double quote inside string System.out.print("He said \"Hi!\""); He said "Hi!"
\\ A literal backslash System.out.print("C:\\Users\\DELL"); C:\Users\DELL

6. Formatted Printing with System.out.printf()

When building financial dashboards or inventory tables, concatenation with + gets messy and cannot control decimal rounding. Java provides System.out.printf() (Print Formatted) using format specifiers:

Specifier Data Type Usage Example Result
%s String text printf("User: %s", "Alex") User: Alex
%d Decimal Integer (int, long) printf("Items: %d", 42) Items: 42
%f Floating-point (float, double) printf("Tax: %f", 7.5) Tax: 7.500000
%.2f Float rounded to 2 decimal places printf("Price: $%.2f", 19.995) Price: $20.00
%-15s Left-aligned string in 15 spaces printf("%-15s", "Total") Total          
%n Platform-independent newline printf("End%n") Jumps to next line

7. Java Operators Demystified

A. Arithmetic Operators

+ (Addition), - (Subtraction), * (Multiplication), / (Division), % (Modulus / Remainder).

⚠️ The Integer Division Trap

When you divide two integers, Java drops any fractional decimal part completely!
int result = 7 / 2; // Evaluates to 3, NOT 3.5!
To get decimal precision, at least one number must be a decimal:
double correct = 7.0 / 2; // Evaluates to 3.5

B. Relational (Comparison) Operators

Always evaluate to a boolean (either true or false):

  • == : Equal to (e.g. 5 == 5 is true)
  • != : Not equal to (e.g. 5 != 3 is true)
  • > and >= : Greater than, Greater than or equal to
  • < and <= : Less than, Less than or equal to

C. Logical Operators

  • && (Logical AND): Returns true ONLY if BOTH sides are true.
  • || (Logical OR): Returns true if AT LEAST ONE side is true.
  • ! (Logical NOT): Flips true to false and vice versa.

D. Increment / Decrement Operators

count++ (Postfix: use current value, then add 1)
++count (Prefix: add 1 immediately, then use new value)

E. The Ternary Operator (Inline If/Else)

Java 
// Syntax: variable = (condition) ? valueIfTrue : valueIfFalse;
int examScore = 78;
String outcome = (examScore >= 50) ? "PASSED" : "FAILED";

8. Type Casting: Widening vs. Narrowing

Type Casting is converting a value from one data type into another.

☕ Analogy: The Coffee Mug and the Thermos

Pouring a small espresso cup into a large thermos is completely safe—it won't spill. That's Widening (Implicit) Casting.
Pouring a gallon thermos into a small espresso cup risks hot coffee spilling all over the table. That's Narrowing (Explicit) Casting—you must confirm you accept the spill!

Java Casting Syntax 
// 1. Widening (Implicit / Automatic) - Smaller to Larger: SAFE
int smallCup = 100;
double largeThermos = smallCup; // Automatic conversion to 100.0

// 2. Narrowing (Explicit / Manual) - Larger to Smaller: DATA LOSS POSSIBLE
double exactBill = 89.95;
int wholeDollars = (int) exactBill; // Truncates .95! wholeDollars is 89!

9. Common Beginner Mistakes to Avoid

🚨 Forgetting the 'L' on Long or 'F' on Float

By default, Java treats whole numbers as int and decimals as double.
long big = 9000000000; // Error: integer number too large!
Fix: Append an 'L' → long big = 9000000000L;
float price = 9.99; // Error: incompatible types: possible lossy conversion from double to float!
Fix: Append an 'f' → float price = 9.99f;

🚨 Comparing with '=' instead of '=='

A single equals = is the assignment operator (stores a value). A double equals == is the comparison operator (checks equality).

10. Executive Quick-Recap & Cheat Sheet

Everything you need to remember about Java variables and data types at a single glance:

⚡ The 30-Second Mental Model

RAM is organized into named slots. Primitives (like int and double) hold their actual bits right in stack memory. References (like String) hold memory addresses pointing to objects on the heap. Narrowing a type (pouring a gallon into a cup) chops off extra bits—always be intentional with type casting!

Common Variable Declarations

Java Cheat Sheet 
// 1. Primitive Declarations
int count = 42;
double price = 19.99;
boolean isCompleted = true;
char status = 'A';

// 2. Literals with Suffixes
long nationalId = 9876543210L; // 'L' suffix
float taxRate = 0.075f;        // 'f' suffix

// 3. Formatted Currency Output
System.out.printf("Invoice Total: $%-8.2f (Tax: %.1f%%)%n", price, (taxRate * 100));

// 4. Casting
int roundedDollars = (int) price; // Explicit cast: 19.99 -> 19

Plain-English Glossary

Primitive Type

One of 8 built-in Java data types that directly store raw values (integers, floating points, characters, or booleans) in memory.

Reference Type (String)

A variable that does not hold the data directly, but stores a pointer/address to an object located in heap memory.

Widening (Implicit)

Automatically converting a smaller numeric type (e.g. int) into a larger type (e.g. double) with zero chance of data loss.

Narrowing (Explicit)

Manually converting a larger type into a smaller type using (targetType), which may discard decimal fractions or cause integer overflow.

Modulus (%)

An arithmetic operator that returns the mathematical remainder after integer division (e.g. 14 % 4 = 2).

Format Specifier (%.2f)

A placeholder code used in System.out.printf() to control exact decimal alignment and padding.

11. Summary & Interactive Self-Checks

Test your intuition on these three quick scenario checks before proceeding to the class lab:

❓ Question 1: What is stored in `int answer = 7 / 2;` and why isn't it 3.5?
Answer: answer will hold 3. In Java, dividing two integers performs integer division, which truncates (discards) the fractional .5. To get 3.5, write 7.0 / 2 or 7 / 2.0.
❓ Question 2: Why do we write `float f = 4.5f;` but `double d = 4.5;`?
Answer: In Java, all decimal literals are treated as 64-bit double values by default. Without the f suffix, assigning a 64-bit double to a 32-bit float causes a compiler error for potential loss of precision.
❓ Question 3: Does casting `(int) 9.99` round the number up to 10?
Answer: No! Type casting does not perform mathematical rounding; it simply chops off the decimal part entirely. (int) 9.99 yields 9.
