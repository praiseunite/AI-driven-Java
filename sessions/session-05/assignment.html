📋 Assignment 5: Campus Library Book Tracker

Model a single library title as a class that protects its own copy counts and exposes only safe operations — your first properly encapsulated domain object.

🏢 Scenario

The Aptech campus library wants a small class, LibraryBook.java, to track how many copies of a title are on the shelf versus out on loan. The counts must never go negative and must always add up — so no outside code may change them directly.

Requirements

  1. Class & file: LibraryBook.java with public class LibraryBook.
  2. Fields (all private): String title, String author, int copiesAvailable, int copiesLent.
  3. Constructor LibraryBook(String title, String author, int totalCopies): set copiesAvailable to totalCopies (clamp negatives to 0), copiesLent to 0. Use this..
  4. borrow(): if copiesAvailable == 0, print a "no copies available" message; otherwise move one copy from available to lent and print the new counts.
  5. returnCopy(): if copiesLent == 0, print a "no copies lent" message; otherwise move one copy back and print.
  6. getCopiesAvailable(): a getter returning the count.
  7. status(): return "ALL OUT" when none available, "FULLY STOCKED" when none lent, otherwise "PARTIALLY LENT".
  8. toString(): return a one-line description including title, author, status, and both counts.
  9. main: create a title with 2 total copies and run: borrow, borrow, borrow (rejected), return, return, return (rejected), then print the object.
Expected Console Output:
Borrowed "Effective Java". Available: 1, Lent: 1
Borrowed "Effective Java". Available: 0, Lent: 2
"Effective Java": no copies available to borrow.
Returned "Effective Java". Available: 1, Lent: 1
Returned "Effective Java". Available: 2, Lent: 0
"Effective Java": no copies are currently lent.
Effective Java by Bloch [FULLY STOCKED] (avail 2 / lent 0)
ℹ️ Layout is yours; behaviour is graded

Your exact wording/spacing may differ. What is graded: fields are private, counts never go negative and always sum to the total, the two rejection paths work, and status() / toString() return (not print) their text. A full reference implementation: the solution.
