📋 Assignment 9: Campus Media Library

Design an abstract base type with concrete subclasses that differ only in one calculation, then drive them polymorphically from a single array.

🏢 Scenario

The library lends books, DVDs, and magazines. They share almost all behaviour (check-out, check-in, "is it out?") but charge different late fees per day.

Requirements

  1. abstract class MediaItem (file MediaLibrary.java):
    • private final String title; and private boolean checkedOut = false;.
    • Constructor takes the title. Getters getTitle(), isCheckedOut().
    • checkOut() — reject if already out; else mark out and print.
    • checkIn(int daysLate) — reject if not out; else mark in, compute fee = max(daysLate,0) * lateFeePerDay(), print it.
    • abstract double lateFeePerDay(); — no body.
    • toString() — title, [IN]/[OUT], and the daily fee.
  2. Subclasses Book ($0.25/day), DVD ($1.00/day), Magazine ($0.10/day) — each just implements lateFeePerDay().
  3. main in MediaLibrary: put one of each in a MediaItem[]; print the catalogue; check out the book and DVD (try the DVD twice); check the book in 3 days late, the DVD 5 days late, the magazine (which was never out); then print the total late fees for the session.
Expected Console Output:
=== CATALOGUE ===
Effective Java         [IN]  ($0.25/day late)
The Matrix             [IN]  ($1.00/day late)
Nature - Jan           [IN]  ($0.10/day late)

=== ACTIVITY ===
Checked out: Effective Java
Checked out: The Matrix
"The Matrix" is already out.
Returned: Effective Java         3 days late  fee $0.75
Returned: The Matrix             5 days late  fee $5.00
"Nature - Jan" was not out.

Total late fees this session: $5.75
