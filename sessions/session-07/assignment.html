📋 Assignment 7: Café Order System — Packaged & Shipped as a JAR

Build a two-class project inside a package, using a class-wide constant and a shared counter, then bundle it into an executable JAR that runs with java -jar.

🏢 Scenario

The Aptech campus café wants a tiny receipt program it can hand to staff as one runnable file. Organise it as the package com.aptech.cafe.

Requirements

  1. Package: both files declare package com.aptech.cafe; and live under com/aptech/cafe/.
  2. MenuItem.java:
    • public static final double TAX_RATE = 0.08; — a class-wide constant.
    • private static int itemsOnMenu = 0; — a shared counter, bumped in the constructor; exposed by public static int getItemsOnMenu().
    • private final String name; private final double price; set in the constructor (clamp a negative price to 0).
    • Getters getName(), getPrice(); priceWithTax() returns price * (1 + TAX_RATE); a readable toString().
  3. CafeApp.java: holds main. Build a MenuItem[] of three items (Espresso 2.50, Muffin 3.25, Sandwich 5.75), print each, total the subtotal, add tax (using MenuItem.TAX_RATE), print the total and MenuItem.getItemsOnMenu().
  4. Run it two ways and confirm identical output:
    Terminal
    javac -d out $(find . -name "*.java")
java -cp out com.aptech.cafe.CafeApp

jar --create --file cafe.jar --main-class com.aptech.cafe.CafeApp -C out .
java -jar cafe.jar
    In IntelliJ: build a JAR artifact (Project Structure → Artifacts) and run it.
Expected Console Output (both ways):
=== APTECH CAFE RECEIPT ===
Espresso         $  2.50  (with tax $  2.70)
Muffin           $  3.25  (with tax $  3.51)
Sandwich         $  5.75  (with tax $  6.21)
---------------------------------------------
Subtotal                             $ 11.50
Tax (8%)                             $  0.92
TOTAL                                $ 12.42
Distinct items defined on menu: 3
