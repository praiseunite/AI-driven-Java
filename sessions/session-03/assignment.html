📋 Assignment 3: Automated ATM Banking Machine Simulator

Combine nested decision constructs (if-else, switch), loop control structures (do-while / while), and jump statements to engineer an interactive Automated Teller Machine (ATM).

🏢 Banking System Scenario

Apex National Bank has hired your Aptech engineering team to prototype the core transaction state-machine for their next-generation ATM kiosk. Your application, named AtmBankingEngine.java, must securely handle customer transactions, enforce business rules (insufficient funds, overdraft protection, daily withdrawal limits), and loop through a menu until the session terminates.

Technical Requirements & Specifications

  1. Class & File Name: Must be declared in AtmBankingEngine.java.
  2. Account Initialization: Initialize an account with an initial balance of $1,500.00 and an authorized PIN (e.g. 2026).
  3. PIN Authentication (Loop):
    • Allow the user up to 3 PIN entry attempts using a while or for loop.
    • If the correct PIN is entered, grant access and break out of the auth loop.
    • If 3 incorrect attempts occur, lock the card and terminate the program using System.exit(0) or break.
  4. Interactive Menu (Loop & Switch):
    • Option 1: Check Balance → Displays current balance formatted to 2 decimal places.
    • Option 2: Deposit Funds → Validates amount (> $0), adds to balance, prints new balance.
    • Option 3: Withdraw Funds → Validates amount:
      • Cannot be ≤ 0.
      • Cannot exceed current account balance (reject with "Insufficient Funds").
      • Cannot exceed daily limit of $500.00 per single transaction.
    • Option 4: Print Mini-Statement → Displays transaction count and final balance.
    • Option 5: Exit & Eject Card → Terminates the loop gracefully.
