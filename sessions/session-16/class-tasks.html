🟢 Milestone 1

Catalogue with a record and a Map S14, S6

Do: Define record Book(String isbn, String title, String genre, double price). Put 4 books in a LinkedHashMap<String, Book> keyed by ISBN and print them as a table.

Javamilestone 1 skeleton
import java.util.*;

public class BookstoreApp {
    record Book(String isbn, String title, String genre, double price) {}

    public static void main(String[] args) {
        Map<String, Book> catalogue = new LinkedHashMap<>();
        catalogue.put("978-1", new Book("978-1", "Effective Java", "tech", 45.00));
        catalogue.put("978-2", new Book("978-2", "Clean Code", "tech", 38.00));
        catalogue.put("978-3", new Book("978-3", "Dune", "sci-fi", 18.50));
        catalogue.put("978-4", new Book("978-4", "The Hobbit", "fantasy", 14.00));

        catalogue.forEach((isbn, b) ->
            System.out.printf("%-6s %-16s %-8s $%.2f%n", isbn, b.title(), b.genre(), b.price()));
    }
}
Expected Console Output:

978-2  Clean Code       tech     $38.00
978-3  Dune             sci-fi   $18.50
978-4  The Hobbit       fantasy  $14.00
🟡 Milestone 2

Orders: LineItem + encapsulated Order + static id S5, S7, S14

Do: Add record LineItem(Book book, int qty) with a total(), and a final class Order with a private static int nextId counter, a private final List<LineItem> (copy it), and a stream-based subtotal(). Build two orders and print their ids + subtotals.

Javamilestone 2 additions
record LineItem(Book book, int qty) {
    double total() { return book.price() * qty; }
}

static final class Order {
    private static int nextId = 1000;
    private final int id = nextId++;
    private final List<LineItem> items;
    Order(List<LineItem> items) { this.items = List.copyOf(items); }
    int id() { return id; }
    List<LineItem> items() { return items; }
    double subtotal() { return items.stream().mapToDouble(LineItem::total).sum(); }
}
Example (books "Effective Java" x2 + "Dune" x1, then "Dune" x3):
Order #1000 subtotal $108.50
Order #1001 subtotal $55.50
🟡 Milestone 3

Discounts: an interface + polymorphic implementations S10, S9

Do: Add interface Discount { double apply(double subtotal); String label(); } and three implementations — NoDiscount, PercentOff(double pct), BulkDeal ($5 off per full $50). Give Order a Discount field and a total() that calls discount.apply(subtotal()). Print each order's discount label, subtotal, and total.

Javamilestone 3 additions
interface Discount {
    double apply(double subtotal);
    String label();
}
static final class NoDiscount implements Discount {
    public double apply(double s) { return s; }
    public String label() { return "none"; }
}
static final class PercentOff implements Discount {
    private final double pct;
    PercentOff(double pct) { this.pct = pct; }
    public double apply(double s) { return s * (1 - pct / 100); }
    public String label() { return (int) pct + "% off"; }
}
static final class BulkDeal implements Discount {
    public double apply(double s) { return s - 5 * Math.floor(s / 50); }
    public String label() { return "$5 per $50"; }
}
// Order gains:  private final Discount discount;
//               double total() { return discount.apply(subtotal()); }
Example:
Order #1000 [10% off]  subtotal $108.50 -> total $97.65
Order #1001 [$5 per $50]  subtotal $42.00 -> total $42.00
🔴 Milestone 4

Bookstore + checkout with OutOfStockException (validate then commit) S6, S11

Do: Add a final class Bookstore holding the catalogue, a Map<String,Integer> stock, and an order history List. Write Order checkout(Map<String,Integer> cart, Discount d, LocalDateTime when) throws OutOfStockException that validates every line first, throws (all-or-nothing) if any exceeds stock, and only then subtracts stock and records the order. In main, run one order that succeeds and one that is rejected.

Javacheckout shape
Order checkout(Map<String, Integer> cart, Discount discount, LocalDateTime when)
        throws OutOfStockException {
    List<LineItem> lines = new ArrayList<>();
    for (var entry : cart.entrySet()) {
        Book b = catalogue.get(entry.getKey());
        if (b == null) throw new OutOfStockException("unknown ISBN " + entry.getKey());
        int want = entry.getValue(), have = stock.getOrDefault(b.isbn(), 0);
        if (want > have)
            throw new OutOfStockException("\"" + b.title() + "\": wanted " + want + ", only " + have + " in stock");
        lines.add(new LineItem(b, want));
    }
    for (LineItem li : lines) stock.merge(li.book().isbn(), -li.qty(), Integer::sum);  // commit
    Order o = new Order(lines, discount, when);
    orders.add(o);
    return o;
}
Example:
Order #1000 committed
REJECTED order: "Clean Code": wanted 5, only 4 in stock
(stock for Clean Code is still 4)
🔴 Milestone 5

Stream reports + timestamps S13, S14

Do: Timestamp orders with LocalDateTime and print them via DateTimeFormatter. Add stream methods to Bookstore: totalRevenue(), revenueByGenre() (flatMap line items → groupingBy(genre, summingDouble)), bestSellers(int topN) (group qty by title, sort desc, limit), lowStockCount(int threshold). Print the full report.

Javareport methods
double totalRevenue() {
    return orders.stream().mapToDouble(Order::total).sum();
}
Map<String, Double> revenueByGenre() {
    return orders.stream()
        .flatMap(o -> o.items().stream())
        .collect(Collectors.groupingBy(li -> li.book().genre(),
                 Collectors.summingDouble(LineItem::total)));
}
List<String> bestSellers(int topN) {
    return orders.stream()
        .flatMap(o -> o.items().stream())
        .collect(Collectors.groupingBy(li -> li.book().title(),
                 Collectors.summingInt(LineItem::qty)))
        .entrySet().stream()
        .sorted(Map.Entry.<String, Integer>comparingByValue().reversed())
        .limit(topN)
        .map(e -> e.getKey() + " (" + e.getValue() + ")")
        .toList();
}
